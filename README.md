**Expense Tracker** is a lightweight yet powerful single-page web application with Firebase Authentication designed to help individuals and families manage their daily expenses efficiently. Built entirely with vanilla JavaScript and modern web technologies, it provides a seamless experience for tracking spending, analyzing monthly trends, and comparing expenses across family members — all without requiring a backend server.

> 💡 **Why this project?** Managing money is hard. This app solves the problem of scattered expense tracking by providing a clean, intuitive interface with instant visual feedback.
